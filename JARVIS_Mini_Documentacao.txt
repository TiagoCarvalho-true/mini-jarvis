Visão Geral do Projeto               O JARVIS Mini é um assistente físico inteligente inspirado no J.A.R.V.I.S. da franquia Iron Man. O projeto combina hardware embarcado de baixo custo com tecnologias modernas de Inteligência Artificial para criar um dispositivo interativo capaz de compreender comandos de voz, executar ações físicas, reconhecer usuários e responder de forma natural.                     O sistema foi projetado para ser modular, expansível e de fácil implementação, tornando-o ideal para fins educacionais, demonstrativos ou para uso residencial.                        Objetivos                    Criar um assistente de voz físico com IA conversacional                    Integrar automação residencial com comandos em linguagem natural                    Implementar reconhecimento facial para personalização                    Demonstrar integração prática entre IA e IoT                    Manter custo acessível com componentes disponíveis no mercado nacional                                2. Funcionalidades                  Núcleo do Sistema                    Ativação por wake word (&quot;Jarvis&quot;)                    Transcrição de voz em tempo real (Whisper API)                    Conversa com IA em linguagem natural (ChatGPT)                    Resposta em áudio sintetizado (TTS)                    Memória contextual de conversas                        Automação Residencial                    Acionamento de LEDs por comando de voz                    Controle de relés (ventiladores, lâmpadas, etc.)                    Modo noturno automático                    Comunicação via protocolo MQTT                        Interface Visual                    Display OLED com animações de olhos                    Exibição de status (escutando / pensando / falando)                    Temperatura e informações do ambiente                        Reconhecimento e Identidade                    Reconhecimento facial com OpenCV                    Saudação personalizada por usuário                    Câmera via Webcam USB ou ESP32-CAM                        Integrações Externas                    Notificações via Telegram Bot                    Integração com WhatsApp (via Twilio/Z-API)                                3.
